# Syntax Basics

Parallax syntax is designed to be familiar yet distinctive, borrowing the best ideas from functional and systems programming languages while maintaining consistency and clarity.

This section is divided into the following parts:

- [Expressions](./expressions.md) - Everything is an expression, including operators and control flow
- [Collections](./collections.md) - Vectors, maps, and sets
- [Functions](./functions.md) - Function definitions and closures
- [Types](./types.md) - Type system basics and custom types
- [Comments](./comments.md) - Documentation and code comments
- [Modules](./modules.md) - Code organization and visibility
- [Keywords](./keywords.md) - Identifiers and reserved words
