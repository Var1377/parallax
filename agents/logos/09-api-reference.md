# API Reference

This chapter provides a comprehensive reference for all Logos APIs, traits, types, and attributes available in version 0.15.

## Core Traits

### `Logos<'source>`

The main trait that defines a lexer for a token enum.

```rust
pub trait Logos<'source>: Sized {
    type Extras;
    type Source: Source + ?Sized + 'source;
    type Error: Default + Clone + PartialEq + Debug + 'source;

    fn lex(lexer: &mut Lexer<'source, Self>);
    fn lexer(source: &'source Self::Source) -> Lexer<'source, Self>
    where
        Self::Extras: Default;
    fn lexer_with_extras(
        source: &'source Self::Source,
        extras: Self::Extras,
    ) -> Lexer<'source, Self>;
}
```

#### Associated Types

- **`Extras`**: Custom state that can be accessed in callbacks
- **`Source`**: The source type to lex from (usually `str` or `[u8]`)
- **`Error`**: Custom error type for lexing failures

#### Methods

- **`lexer(source)`**: Create a new lexer with default extras
- **`lexer_with_extras(source, extras)`**: Create a new lexer with custom extras
- **`lex(lexer)`**: Internal method generated by the derive macro

#### Example

```rust
use logos::Logos;

#[derive(Logos, Debug, PartialEq)]
#[logos(extras = usize)]  // Line counter
#[logos(error = MyError)]
enum Token {
    #[token("hello")]
    Hello,
    
    #[regex("[a-zA-Z]+")]
    Word,
}

// Usage
let mut lexer = Token::lexer("hello world");
let mut lexer_with_extras = Token::lexer_with_extras("hello world", 0);
```

## Core Types

### `Lexer<'source, Token>`

The main lexer struct that produces tokens.

```rust
pub struct Lexer<'source, Token: Logos<'source>> {
    pub extras: Token::Extras,
    // private fields...
}
```

#### Methods

##### Navigation and State

```rust
impl<'source, Token: Logos<'source>> Lexer<'source, Token> {
    // Create new lexer
    pub fn new(source: &'source Token::Source) -> Self
    where
        Token::Extras: Default;
    
    pub fn with_extras(source: &'source Token::Source, extras: Token::Extras) -> Self;
    
    // Get source information
    pub fn source(&self) -> &'source Token::Source;
    pub fn slice(&self) -> &'source <Token::Source as Source>::Slice;
    pub fn span(&self) -> Span;
    pub fn remainder(&self) -> &'source <Token::Source as Source>::Slice;
    
    // Manual navigation
    pub fn bump(&mut self, n: usize);
}
```

##### Iterator Implementation

```rust
impl<'source, Token: Logos<'source>> Iterator for Lexer<'source, Token> {
    type Item = Result<Token, Token::Error>;
    
    fn next(&mut self) -> Option<Self::Item>;
}
```

##### Spanned Iterator

```rust
impl<'source, Token: Logos<'source>> Lexer<'source, Token> {
    pub fn spanned(self) -> SpannedIter<'source, Token>;
}
```

#### Example

```rust
use logos::Logos;

#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("hello")]
    Hello,
    
    #[regex("[a-zA-Z]+")]
    Word,
}

let mut lexer = Token::lexer("hello world");

// Basic iteration
while let Some(token) = lexer.next() {
    match token {
        Ok(token) => println!("Token: {:?}", token),
        Err(_) => println!("Error at: {:?}", lexer.span()),
    }
}

// Access lexer state
println!("Current slice: {}", lexer.slice());
println!("Current span: {:?}", lexer.span());
println!("Remaining: {}", lexer.remainder());

// Manual navigation
lexer.bump(1); // Skip one character
```

#### Example

```rust

        Err(_) => println!("Error at {:?}", span),
    }
}
```

### `Span`

Type alias for byte ranges in the source.

```rust

```

#### Example

```rust

println!("Start: {}, End: {}, Length: {}", span.start, span.end, span.len());
```

## Callback Return Types

### `Skip`

Type that instructs the lexer to skip the current match.

```rust
pub struct Skip;
```

#### Example

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[regex(r"[ \t]+", |_| Skip)]
    Whitespace,
    
    #[regex("[a-zA-Z]+")]
    Word,
}
```

### `Filter<T>`

Enum that allows emitting a token or skipping it.

```rust
pub enum Filter<T> {
    Emit(T),
    Skip,
}
```

#### Example

```rust
use logos::{Logos, Filter};

#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[regex("[0-9]+", |lex| {
        let n: u32 = lex.slice().parse().unwrap();
        if n % 2 == 0 {
            Filter::Emit(n)
        } else {
            Filter::Skip
        }
    })]
    EvenNumber(u32),
}
```

### `FilterResult<T, E>`

Enum that allows emitting a token, skipping it, or returning an error.

```rust
pub enum FilterResult<T, E> {
    Emit(T),
    Skip,
    Error(E),
}
```

#### Example

```rust
use logos::{Logos, FilterResult};

#[derive(Debug, PartialEq, Clone, Default)]
enum LexError {
    #[default]
    InvalidToken,
    NumberTooLarge,
}

#[derive(Logos, Debug, PartialEq)]
#[logos(error = LexError)]
enum Token {
    #[regex("[0-9]+", |lex| {
        match lex.slice().parse::<u32>() {
            Ok(n) if n <= 100 => FilterResult::Emit(n),
            Ok(_) => FilterResult::Error(LexError::NumberTooLarge),
            Err(_) => FilterResult::Skip,
        }
    })]
    SmallNumber(u32),
}
```

## Attributes

### `#[derive(Logos)]`

The main derive macro that implements the `Logos` trait.

```rust
#[derive(Logos, Debug, PartialEq)]

    // Token definitions...
}
```

### `#[logos(...)]` - Enum Attributes

Global configuration for the lexer.

#### `skip`

Define global skip patterns.

```rust
#[derive(Logos, Debug, PartialEq)]
#[logos(skip r"[ \t\n\f]+")]           // Skip whitespace
#[logos(skip r"//[^\n]*")]             // Skip line comments
#[logos(skip r"/\*([^*]|\*[^/])*\*/")]  // Skip block comments
enum Token {
    // Token definitions...
}
```

#### `error`

Define custom error type.

```rust
#[derive(Debug, PartialEq, Clone, Default)]
enum MyError {
    #[default]
    InvalidToken,
    CustomError,
}

#[derive(Logos, Debug, PartialEq)]
#[logos(error = MyError)]
enum Token {
    // Token definitions...
}
```

#### `error` with callback

Define custom error type with error callback.

```rust
impl MyError {
    fn from_lexer(lex: &mut Lexer<Token>) -> Self {
        // Custom error logic
        MyError::CustomError
    }
}

#[derive(Logos, Debug, PartialEq)]
#[logos(error(MyError, MyError::from_lexer))]
enum Token {
    // Token definitions...
}
```

#### `extras`

Define custom extras type.

```rust
#[derive(Default)]
struct MyExtras {
    line: usize,
    column: usize,
}

#[derive(Logos, Debug, PartialEq)]
#[logos(extras = MyExtras)]
enum Token {
    // Token definitions...
}
```

#### `source`

Define custom source type.

```rust

    #[regex(b"[a-zA-Z]+")]

}
```

#### `export_dir`

Export debug graphs for visualization.

```rust

    // Token definitions...
}
```

### `#[token(...)]` - Literal Token Attributes

Define tokens that match exact strings.

#### Basic Usage

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("hello")]
    Hello,
    
    #[token("world")]
    World,
    
    #[token("==")]
    Equal,
}
```

#### With Callback

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("true", |_| true)]
    #[token("false", |_| false)]
    Bool(bool),
    
    #[token("null", |_| ())]
    Null,
}
```

#### With Priority

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("=", priority = 1)]
    Assign,
    
    #[token("==", priority = 2)]  // Higher priority
    Equal,
}
```

### `#[regex(...)]` - Regular Expression Attributes

Define tokens that match regular expression patterns.

#### Basic Usage

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[regex("[a-zA-Z]+")]
    Word,
    
    #[regex("[0-9]+")]
    Number,
    
    #[regex(r#""([^"\\]|\\.)*""#)]
    String,
}
```

#### With Callback

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[regex("[0-9]+", |lex| lex.slice().parse::<i32>().unwrap())]
    Number(i32),
    
    #[regex(r#""([^"\\]|\\.)*""#, |lex| {
        let s = lex.slice();
        s[1..s.len()-1].to_string()
    })]
    String(String),
}
```

#### Multiple Patterns

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[regex("[0-9]+", |lex| lex.slice().parse::<i32>().unwrap())]
    #[regex("0x[0-9a-fA-F]+", |lex| {
        i32::from_str_radix(&lex.slice()[2..], 16).unwrap()
    })]
    #[regex("0b[01]+", |lex| {
        i32::from_str_radix(&lex.slice()[2..], 2).unwrap()
    })]
    Number(i32),
}
```

## Source Trait

### `Source`

Trait for types that can be used as lexer input.

```rust
pub trait Source {
    type Slice: ?Sized;
    
    fn len(&self) -> usize;
    fn read<T>(&self, offset: usize) -> Option<T>
    where
        T: Chunk<Self::Slice>;
    unsafe fn read_unchecked<T>(&self, offset: usize) -> T
    where
        T: Chunk<Self::Slice>;
    fn slice(&self, range: Range<usize>) -> Option<&Self::Slice>;
    unsafe fn slice_unchecked(&self, range: Range<usize>) -> &Self::Slice;
}
```

#### Implementations

Logos provides implementations for common types:

- `str` - UTF-8 string slices
- `[u8]` - Byte slices
- `String` - Owned strings
- `Vec<u8>` - Owned byte vectors

#### Custom Implementation

```rust
use logos::{Source, Chunk};
use std::ops::Range;

struct CustomSource {
    data: Vec<char>,
}

impl Source for CustomSource {
    type Slice = [char];
    
    fn len(&self) -> usize {
        self.data.len()
    }
    
    fn read<T>(&self, offset: usize) -> Option<T>
    where
        T: Chunk<Self::Slice>,
    {
        T::read(&self.data, offset)
    }
    
    unsafe fn read_unchecked<T>(&self, offset: usize) -> T
    where
        T: Chunk<Self::Slice>,
    {
        T::read_unchecked(&self.data, offset)
    }
    
    fn slice(&self, range: Range<usize>) -> Option<&Self::Slice> {
        self.data.get(range)
    }
    
    unsafe fn slice_unchecked(&self, range: Range<usize>) -> &Self::Slice {
        self.data.get_unchecked(range)
    }
}
```

## Error Handling

### Default Error Type

When no custom error type is specified, Logos uses `()`:

```rust
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("hello")]
    Hello,
}

// Error type is ()
let mut lexer = Token::lexer("hello @");
assert_eq!(lexer.next(), Some(Ok(Token::Hello)));
assert_eq!(lexer.next(), Some(Err(())));
```

### Custom Error Types

Custom error types must implement required traits:

```rust
#[derive(Debug, PartialEq, Clone, Default)]
enum MyError {
    #[default]
    InvalidToken,
    InvalidNumber,
    UnterminatedString,
}

#[derive(Logos, Debug, PartialEq)]
#[logos(error = MyError)]
enum Token {
    #[regex("[0-9]+", |lex| lex.slice().parse::<u32>())]
    Number(u32),
}
```

### Error Conversion

Implement `From` traits for automatic error conversion:

```rust
use std::num::ParseIntError;

impl From<ParseIntError> for MyError {
    fn from(_: ParseIntError) -> Self {
        MyError::InvalidNumber
    }
}
```

## Advanced Features

### Context-Dependent Lexing

Use the `morph` method to switch between lexer contexts:

```rust
impl<'source, Token: Logos<'source>> Lexer<'source, Token> {
    pub fn morph<Token2>(self) -> Lexer<'source, Token2>
    where
        Token2: Logos<'source, Source = Token::Source>,
        Token::Extras: Into<Token2::Extras>;
}
```

#### Example

```rust
#[derive(Logos, Debug, PartialEq, Clone)]
enum MainToken {
    #[token("\"", enter_string_mode)]
    StringStart(Vec<StringToken>),
    
    #[regex("[a-zA-Z]+")]
    Word,
}

#[derive(Logos, Debug, PartialEq, Clone)]
enum StringToken {
    #[token("\"")]
    StringEnd,
    
    #[regex("[^\"]+")]
    Content,
}

fn enter_string_mode(lex: &mut Lexer<MainToken>) -> Option<Vec<StringToken>> {
    let mut string_lexer = lex.clone().morph::<StringToken>();
    let mut tokens = Vec::new();
    
    while let Some(Ok(token)) = string_lexer.next() {
        if matches!(token, StringToken::StringEnd) {
            break;
        }
        tokens.push(token);
    }
    
    *lex = string_lexer.morph();
    Some(tokens)
}
```

### Extras Usage

Access and modify lexer state through the `extras` field:

```rust
#[derive(Default)]
struct LineCounter {
    line: usize,
    column: usize,
}

#[derive(Logos, Debug, PartialEq)]
#[logos(extras = LineCounter)]
enum Token {
    #[regex(r"\n", |lex| {
        lex.extras.line += 1;
        lex.extras.column = 0;
        lex.extras.line
    })]
    Newline(usize),
    
    #[regex("[a-zA-Z]+", |lex| {
        let word = lex.slice().to_string();
        lex.extras.column += word.len();
        (word, lex.extras.line, lex.extras.column)
    })]
    Word(String, usize, usize),
}
```

## Performance Considerations

### Memory Layout

Keep token enums compact for better cache performance:

```rust
// ✅ Good - compact enum
#[derive(Logos, Debug, PartialEq)]
enum CompactToken {
    Keyword(u8),    // Use indices
    Number(u32),    // Appropriate size
    Operator(u8),
}

// ❌ Poor - large enum
enum LargeToken {
    Keyword(String),    // Heap allocation
    Number(u64),        // Unnecessarily large
    Operator(String),   // Heap allocation
}
```

### Callback Performance

Keep callbacks simple and fast:

```rust
// ✅ Fast callback
#[regex("[0-9]+", |lex| lex.slice().parse::<u32>().unwrap())]
Number(u32),

// ❌ Slow callback
#[regex("[0-9]+", |lex| {
    let s = lex.slice();
    let mut result = 0u32;
    for c in s.chars() {
        result = result * 10 + (c as u32 - '0' as u32);
    }
    result
})]
SlowNumber(u32),
```

## Common Patterns

### Programming Language Lexer

```rust
#[derive(Logos, Debug, PartialEq)]
#[logos(skip r"[ \t\n\f]+")]
#[logos(skip r"//[^\n]*")]
#[logos(skip r"/\*([^*]|\*[^/])*\*/")]
enum ProgrammingToken {
    // Keywords
    #[token("fn")] Function,
    #[token("let")] Let,
    #[token("if")] If,
    #[token("else")] Else,
    
    // Operators
    #[token("+")] Plus,
    #[token("-")] Minus,
    #[token("*")] Multiply,
    #[token("/")] Divide,
    #[token("=")] Assign,
    #[token("==")] Equal,
    
    // Delimiters
    #[token("(")] LeftParen,
    #[token(")")] RightParen,
    #[token("{")] LeftBrace,
    #[token("}")] RightBrace,
    #[token(";")] Semicolon,
    
    // Literals
    #[regex(r"[0-9]+", |lex| lex.slice().parse::<i64>().unwrap())]
    Integer(i64),
    
    #[regex(r#""([^"\\]|\\.)*""#, |lex| {
        let s = lex.slice();
        s[1..s.len()-1].to_string()
    })]
    String(String),
    
    // Identifiers (must come after keywords)
    #[regex("[a-zA-Z_][a-zA-Z0-9_]*")]
    Identifier,
}
```

### JSON Lexer

```rust
#[derive(Logos, Debug, PartialEq)]
#[logos(skip r"[ \t\r\n\f]+")]
enum JsonToken {
    #[token("true", |_| true)]
    #[token("false", |_| false)]
    Bool(bool),

    #[token("{")]
    BraceOpen,

    #[token("}")]
    BraceClose,

    #[token("[")]
    BracketOpen,

    #[token("]")]
    BracketClose,

    #[token(":")]
    Colon,

    #[token(",")]
    Comma,

    #[token("null")]
    Null,

    })]
    Number(f64),

    #[regex(r#""([^"\\]|\\(["\\bnfrt/]|u[a-fA-F0-9]{4}))*""#, |lex| {

```

## Migration Guide

### From Logos 0.14 to 0.15

Key changes in version 0.15:

1. **Improved Error Handling**: Better error types and recovery
2. **Enhanced Performance**: Further optimizations
3. **Better Regex Support**: More comprehensive pattern support
4. **Context-dependent Lexing**: Improved morphing support

#### Breaking Changes

- Some internal APIs have changed
- Error handling improvements may require updates
- Performance optimizations may change behavior slightly

#### Migration Steps

1. Update dependency version
2. Review custom error types
3. Test lexer behavior with new optimizations
4. Update any custom source implementations

## Troubleshooting

### Common Issues

#### Compilation Errors

```rust
// ❌ Error: conflicting patterns
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("=")]
    Assign,
    
    #[token("=")]  // Conflict!
    Equal,
}

// ✅ Solution: use different patterns or priorities
#[derive(Logos, Debug, PartialEq)]
enum Token {
    #[token("=")]
    Assign,
    
    #[token("==")]
    Equal,
}
```

#### Performance Issues

```rust
// ❌ Slow: complex regex
#[regex(r"(a+)+b")]
SlowPattern,

// ✅ Fast: simple pattern
#[regex(r"a+b")]
FastPattern,
```

#### Memory Issues

```rust
// ❌ Memory intensive: large tokens
enum Token {

// ✅ Memory efficient: compact tokens

}
```
